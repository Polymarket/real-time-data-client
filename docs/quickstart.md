# Quickstart (Local)

## Install
- `npm install`

## Environment
Set your variables (example names; follow existing code conventions):
- `export WS_URL="..."`
- `export API_KEY="..."`

## Run
- `npm run build`
- `npm run start`

## Troubleshooting
- If the stream is silent, verify the endpoint and network access.
- If auth fails, re-check key formatting and quoting.
